# 抽出はクラウドVision LLM、プロバイダは抽出アダプタ裏で差し替え可能

スクショ・写真・テキストからの日付抽出は、端末内OCRではなくクラウドのVision LLM（Claude / Gemini 等）に任せる。日本語の雑多なスクショからタイトル・日付・種類を高精度に構造化抽出するには実用上LLMが最速・最良で、端末内OCR＋ルール解析は精度・工数が見合わないから。プロバイダ間のコスト差は個人の利用量では無視できるため決め打ちせず、「抽出アダプタ」という単一インターフェースの裏に隠して差し替え可能にする。

## Consequences

- ローカル完結（[ADR-0001](./0001-local-first-single-device-start.md)）の意図的な例外。抽出の一瞬だけ画像がAPIを通る（保存は端末内、API側は既定で学習に使わない／長期保存しない）。
- 完全オフラインでは抽出できない。
- 正確な料金比較でプロバイダを決め打ちする場合は、その時点の最新価格を確認してから決める。
